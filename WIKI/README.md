## Главный секрет мира

```
Ватра существует не как школа.
А как крышка на гробнице Субъекта 0.

100 реликвий = осколки его тела.
12 преподавателей = живые Печати.
Seekers = стражи, не дающие собрать всё воедино.
```

**Если собрать все реликвии → Субъект 0 пробудится.**  
**Субъект 0 не злодей — он хотел убрать смерть и страдания. Катастрофа вышла случайно.**
